# 烬语者 · Emberspeaker

暗黑风 3D 动作 RPG，运行在浏览器里（Three.js + Vite）。当前内容：**第一集《午夜钟声》、第二集《腐林疫歌》、第三集《铁冠叛旗》**。第三集包含石脊关、叛军营地、铁冠要塞和王座钟楼。

## 运行

需要先安装 [Node.js](https://nodejs.org)（LTS 版本即可）。

- **最省事**：双击 `start-game.command`（macOS）。第一次会自动安装依赖，然后打开浏览器。
- **或者手动**：

```bash
npm install      # 只需第一次
npm run dev      # 启动后浏览器会自动打开
```

建议用 Chrome 或 Edge。画质有「高 / 中 / 低」三档：游戏中按 Esc 打开菜单切换（会自动保存并重新载入），也可以在网址后加 `?q=low` / `?q=mid`。如果高画质下明显卡顿，游戏会提示你降档。

## 职业

开局在选人界面挑职业，每个职业有独立的存档、背包和装备（自动保存在浏览器里，可在选人界面"继续"或"新建"）。

| 职业 | 资源 | 主属性 | 技能（左键 / 右键 / Q / W / E / 空格） |
| --- | --- | --- | --- |
| 战士 | 怒气（攻击和受击获得） | 力量 | 猛砍 / 裂地猛击 / 战吼 / 旋风斩 / 跃击 / 冲锋 |
| 游侠 | 专注 | 敏捷 | 速射 / 多重射击 / 穿透箭 / 箭雨 / 爆裂箭 / 翻滚 |
| 法师 | 法力 | 智力 | 火焰弹 / 火球术 / 冰霜新星 / 闪电链 / 陨石术 / 闪现 |
| 圣骑士 | 法力 | 力量 | 正义打击 / 审判之锤 / 圣光护盾 / 治疗之光 / 奉献 / 盾击冲锋 |
| 死灵法师 | 精魄 | 智力 | 骨刺 / 白骨长矛 / 召唤骷髅 / 尸爆 / 死亡新星 / 骨灵步 |

Q / W / E 技能分别在 2 / 4 / 6 级解锁，点击技能上方的「+」花技能点学习。R 大招在 10 级解锁。

## 装备、背包与商店

- **背包**（I / B 键或左上角"背包"按钮）：左边是装备栏和人物属性，右边 40 格背包。
  - 左键：装备 / 卸下；右键：丢弃到脚下（可以再捡起来，离开区域后消失；丢弃传奇会先确认）
  - 拖动：在背包里整理位置、拖到装备栏穿上、拖到面板外面直接丢弃
  - 鼠标悬停：显示物品大图、属性，以及和身上装备的对比（▲ 更好 / ▼ 更差）
- **外观随装备变化**：武器、盾牌 / 法球 / 箭袋 / 圣物匣、头盔或兜帽、肩甲（胸甲）、护臂（手套）、护胫（靴子）都会实际穿在角色身上，品质越高造型越华丽（钢、黑钢、金边、宝石、发光符文，传奇头盔带角）。
- **品质**：普通（白）→ 魔法（蓝）→ 稀有（黄）→ 传奇（橙）。掉在地上时普通装备不发光，魔法装备有淡蓝光晕，稀有装备有金色光柱，传奇装备有高大的橙色光柱、旋转的符文圈和独特音效。
- **传奇装备只能在野外打**（精英、Boss、宝箱），商店不卖，每件都会改变技能效果。
- **大本营商店**：铁匠布拉姆卖普通和魔法装备（随等级刷新），药剂师艾琳卖药水。打开商店时点背包里的物品可以卖掉（原价 30%）。

```

src/game/classes.js   职业定义（属性、资源、初始装备）
src/game/skills.js    五个职业的技能
src/game/items.js     装备底材、词缀、传奇、掉落与商店
```

## 以后怎么加内容

- **新剧集**：仿照 `src/game/story.js` 的 `Episode1` 写一个新类（`onStart / onTalk / onTrigger / onKill / onLevel`），在 `main.js` 里切换。
- **新地图**：在 `src/game/maps.js` 里用 `room / spawn / torch / npc / trigger / chest / gate` 雕刻一张新图，注册到 `LEVELS`。
- **新敌人**：在 `src/game/enemy.js` 的 `ENEMY_TYPES` 里加一项。
- **新技能 / 新职业**：职业在 `src/game/classes.js`，技能在 `src/game/skills.js` 的 `CLASS_SKILLS`，模型和动作对应在 `src/game/models.js`。
- **新装备 / 新传奇**：在 `src/game/items.js` 的 `BASES` / `AFFIXES` / `LEGENDARIES` 里加。
- **替换成录制音效**：把 `xxx.ogg` 放进 `public/audio/`，并在 `public/audio/manifest.json` 里列出名字（如 `["fireball","explosion"]`），同名的合成音效会被替换。可用的名字见 `src/core/audio.js` 末尾的 `SFX`。

## 素材与授权

- **人物与怪物（写实）**：Adobe Mixamo 的角色和动作捕捉动画，已转换为 `public/assets/mx/` 下的 GLB（每个角色约 1MB，贴图压缩为 1024px WebP），所有角色共用一个动画库 `anims.glb`。Mixamo 素材可免费用于个人和商业项目（需遵守 Adobe 的条款，不能把模型文件本身单独转售或分发）。
  - 五个职业角色、药剂师艾琳（Arissa）、罗兰、布拉姆、薇拉，以及全部怪物和 Boss 都来自 Mixamo
- **场景材质与道具（写实扫描）**：Poly Haven（CC0）。地面、墙面、石材等 PBR 材质在 `public/assets/pbr/`（颜色 / 法线 / AO-粗糙度贴图），木箱、酒桶、雕像、铁门、火盆、宝箱、战锤等模型在 `public/assets/ph/`。
- **技能特效贴图**：Kenney Particle Pack（CC0），合成为 `public/assets/fx/atlas.png`。特效另外用自写着色器实现：噪声溶解的能量环 / 刀光、沸腾的火球核心、投射物拖尾、武器挥砍光带、画面扭曲冲击波和热浪、飞溅的碎石骨片。
- **装备模型和图标**：全部由代码程序化生成（`src/game/gear.js`），背包图标是实时渲染的 3D 模型。
- **技能图标**：图形来自 [game-icons.net](https://game-icons.net)（作者 Lorc、Delapouite，CC BY 3.0 许可，需署名），由 `src/game/skillart.js` 叠加纹理、光照、发光和暗角绘制成最终图标；每个技能用的图形见 `src/game/skillglyphs.js`。
- **职业头像**：由游戏内的角色模型实时渲染。
- **少量风格化小道具**：KayKit Dungeon Remastered（Kay Lousberg，CC0）。
- **音效、环境声、配乐**：Pixabay（Pixabay Content License），裁剪和响度处理后放在 `public/audio/`，逐条来源见 `public/audio/CREDITS.md`。怪物和英雄使用各自独立的技能音效（怪物版本是变调、混响处理后的派生音效）。没有对应文件的声音仍由浏览器实时合成。
- 原始下载文件保存在 `raw/` 文件夹（不参与运行，可以删除，但以后要重新处理素材时会用到）。

### 换模型 / 换动画 / 换声音

- **角色和动画的对应关系**在 `src/game/models.js`：每个角色用哪个模型文件、每个动作用动画库里的哪一段、法术在第几帧释放。
- **预览所有角色**：开发服务器运行时打开 `http://localhost:5173/preview.html`，可以切换动画逐个查看。
- **重新打包 Mixamo 素材**：FBX 转 GLB 后运行 `node tools/pack.mjs <转换目录> public/assets/mx`（需要先 `npm install`）。
- **声音**：在 `public/audio/manifest.json` 里给每个名字列出若干文件（随机挑一个播放，带轻微音高变化），`gain` 控制音量。

## 画面与音效技术（v5）

- **渲染**：屏幕空间环境光遮蔽（墙角、物体接触处的自然阴影）、最近的火把投射实时阴影、地面视差凹凸（石缝真的凹下去）、电影调色（S 曲线、冷暗部暖亮部、暗角、胶片颗粒）、画面扭曲（冲击波、热浪）。
- **环境**：地面随机分布的污渍、裂缝、苔藓、旧血迹；怪物倒下处会慢慢洇开血泊；重击会砸出裂纹；场景里有漂浮的地雾（被火光照亮）和空中的浮尘。
- **特效**：火焰、爆炸、烟、尘土用流体模拟离线烘焙成序列帧（`tools/bake-flipbooks.py`，运行 `python3 tools/bake-flipbooks.py` 可重新生成）；粒子贴近地面时柔和淡出；烟雾会被附近的火光照亮。
- **打击感**：被击杀的怪物按最后一击的力度被击飞、撞墙反弹、落地翻滚滑行；重击时镜头顺着打击方向顿一下。
- **音频**：3D 方位声（HRTF，戴耳机效果最好）、远处声音更闷更空旷、营地/墓穴/钟室三种空间混响、爆炸等重击有低频冲击并短暂压低音乐、脚步声随地面（泥土 / 石板 / 落叶）变化、重甲职业走路有金属碰撞声、战斗时音乐自动打开并加入战鼓。
