# 第三集《铁冠叛旗》· 可玩版本

等级 10–13，主题为被铁律之钟控制的活人军队。两张地图依次推进：石脊关与叛军营地、铁冠要塞与王座钟楼。关卡使用军令和黑铁纹章作为两个明确目标，避免只有长路清怪。

| 遭遇 | 特征 | 玩家应对 |
|---|---|---|
| 关隘盾阵 | 盾卒正面物理减伤，身后弩手和战旗增援 | 拆旗破阵，或西侧旧军械道绕行解除绞盘 |
| 东侧重弩 | 直线长距离预警，箭矢实际命中判定 | 横向避让后近身拆除；破坏结果保存在存档中，减少叛王齐射箭数 |
| 营地督军 | 盾卒、狂战士和刺客组成混合防线 | 控制狂战士，先解决远程与军旗，夺军令开门 |
| 黑铁骑士 | 举盾反击、横斩和直线突进 | 控制破盾，或绕到身后攻击；胜利获得黑铁纹章 |
| 叛王 · 第一阶段 | 举盾、横斩、王剑突进和扇形齐射 | 利用警示与收剑间隙，物理职业避免正面硬打 |
| 叛王 · 第二阶段（65%） | 召出一面血旗，附近单位减伤 20%、攻击提高 25% | 优先拆旗，削弱王庭军阵 |
| 叛王 · 第三阶段（30%） | 最多两面血旗，加入三条平行裁决火线 | 进入火线间的安全走廊；蓄力裁决也可由控制打断 |

预警方向在招式开始时锁定，伤害不追踪玩家。突进终点由现有连续碰撞求解。每次横斩、突进或火线对同一角色最多命中一次。控制破盾后有 3.2 秒伤害提高 25% 的窗口。召唤战旗不提供经验、装备、金币，避免首领战刷资源。

属性对应：火焰克制木质战旗和重弩；闪电对军械护甲有额外收益；物理从侧后方绕过盾牌；战士与圣骑士可留控制技能破盾；死灵召唤物能分担压力并从不同方向攻击。第二集鹿王依然抗毒、弱火，圣光可清除疫病。数值与招式性质体现职业差异，不按职业名称强制增减伤害。

装备均可供五名英雄使用：破阵者之握强化拆军械并奖励控制破盾；铁行军靴奖励连续击杀；废王印玺奖励持续攻击同一目标。Boss 保证本章节传奇。铁冠徽片为该集卖钱特产。普通装备 10 级起显示黑铁，13 级起显示王庭精钢。

击败叛王获得铁律钥舌，在王座后的第三口钟完成反鸣，解读征调运单后引出第四集盐沙古墓。第四集尚未开放，不用未实现的入口冒充可玩内容。战后可返回营地、重返两张第三关地图刷装备；必经剧情奖励和可选目标不会重复发放。

素材沿用既有来源与授权，不新增第三方资源。军旗、弩车、营帐、路障、盔冠、披风和火线为程序几何；使用已加载人形的骨骼绑定。现有风、火、石室环境录音分区混音，并为军阵战斗增加行军节奏。未来可独立替换每名士兵与首领的专属模型。
