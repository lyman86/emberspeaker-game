# 第四集 · 盐沙古墓

本集在第三集铁律反鸣后，从营地西侧或铁冠钟楼的「西行盐道」进入。老存档沿用原有职业存档键，新增 ep4 状态按需初始化，无需重开。13–16 级；两张地图；本集没有新钟，终点是取得古代铸钟图纸。

## 独有流程

灰盐荒原：盐路商人补给 → 清理东西导流碑守军并引光 → 双光路开启日轮石门 → 沙埋神殿。西北可选共鸣盐晶与避风护符，取得后盐后沙暴伤害降低 25%。完成可选路线不会替代主线引光。

沙埋神殿：盐尸与墓守廊道 → 铸钟石刻 → 破坏两侧盐晶、击败封尸祭司 → 解除王陵封印 → 盐后 → 读取铸钟图纸。图纸揭露活人献祭和守夜人的旧印，运单引向第五集沉钩之港。图纸的经验奖励只发放一次。

## 盐之女王 · 瑟芮娅

36000 生命，三阶段 100–70%、70–35%、35% 以下。开场对话后才战斗；死亡重试重置施法、阶段、召唤与特效。Boss 挑战另有显式准备按钮，准备时 Boss 休眠。

- 第一阶段：晶刃扇射，三处盐棱断层，盐沙风暴。圆形和射线预警与实际命中范围相同。
- 第二阶段：补充共鸣盐晶和盐尸；凝冠可被控制打断。盐晶上限按存活数计算，盐尸增援最多补至两只。
- 第三阶段：加入六棱裁决，六条固定射线之间留出可站立空隙，技能间隔缩短。
- 沙暴提前 2 秒标出青色避风圈，持续 4.5 秒；圈内不会受到沙暴伤害，圈外每 0.75 秒受伤。安全圈优先取附近可达位置，不要求跨越整座场地。基础沙暴 70，第三阶段 84，仍经过职业护甲/无敌等现有防御规则。
- 破晶和施法后摇提供 +30% 反击伤害窗口。控制不是硬锁 Boss，而是积累失衡，打断可打断的预备动作。

## 掉落与视觉

本集 Boss 必掉第四集传奇池的一件：避风者的盐纱（沙暴伤害 -35%）、碎日指环（盐晶伤害 +80%，受控目标 +20%）、拾荒者的晶握（破晶回复生命和职业资源）。特产材料灰盐晶砂，单价 22 金币。

复用本地已授权的 Mixamo 骨架、CC0 扫描材质；新增盐晶、裹布、面具盾矛、冠冕飘纱和光路机关为自建几何。荒原采用亮盐地面、低矮盐脊、实例盐晶和流动盐尘；神殿采用冷青光与铸钟石台。没有新增外部运行时请求或第三方下载。

验证包括全图真实碰撞路径、动画名存在、重复触发、旧存档解锁、Boss 对话与准备保护、预警伤害、安全圈减伤、射线空隙、控制打断、增援上限和掉落池。手机横屏用浏览器 844×390 和 667×375 检查；实体手机帧率与完整玩家通关平衡仍需反馈。
