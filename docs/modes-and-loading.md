# 模式与按地图加载

主菜单增加故事模式、关卡挑战、Boss 挑战。关卡和 Boss 可自由选择六集，再选择五种英雄之一。挑战使用对应等级与装备、基础主动技能和剩余可分配技能点；不读取或写入故事职业存档。挑战结算提供用时、倒下次数、重试和返回模式选择。挑战装备和材料仅在本次挑战内生效，不带回故事存档。

故事保持 emberspeaker.save.<职业> 旧键与连续进度。完成第三集即可从西行盐道进入第四集。开发 qa 仍使用独立 emberspeaker.qa.<职业> 键。

## 资源边界

- 英雄大厅：公共动画、五名可选英雄、装备公共纹理与通用战斗粒子。没有关卡怪物、NPC、扫描场景道具或关卡环境音频。
- 进入地图：resources.js 根据本地图地形、道具映射、NPC、敌人、所选职业和首领动态召唤依赖生成模型/材质清单。不会预加载未来章节。
- 读条覆盖模型、纹理和当前环境音；下载中断可原地重试。已成功的资源保留，失败请求可重新发起。
- 跨图：先确保目标资源可用，再清理旧场景、角色、特效与实例；删除不再需要的模型、纹理、材质和解码音频。公共英雄装备纹理保留。已下载文件由浏览器正常 HTTP 缓存复用，回访时不必强制重新下载。
- 音效：清单只读元数据；普通短音效按使用加载，第二集专属音效只在第二集预备，环境与音乐只加载当前 mood。跨关移除不用的专属效果和背景缓存。
- 模式选择、技能成长、装备图标均不依赖外部 CDN。旧 public/assets/chars 虽随站点保留，但没有被运行时请求。

资源依赖检查会运行真实 Level 构造器记录所有扫描道具和材质访问，检查清单覆盖；另外验证重复并发只加载一次、失败重试、释放保留项，以及切图后的音频隔离。运行 npm test。

浏览器检查：手机模式选择与英雄选择；Boss 准备前保持休眠、实时加点、对话后战斗、结算；第一至第四集跨图缓存清单、第二集专属音频清理；第四集引光与图纸流程。自动化测试使用独立 fixture，浏览器测试使用本地 deployment/modes-review.html，不打包到线上。

第六集的山口、修道院及首领挑战沿用同一资源边界；四个冬境 WAV 仅在第六集预备，离开后删除解码缓存。844 像素横屏下六张章节卡排列在同一行，小屏可在中部列表内滚动。
