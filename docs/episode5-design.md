# 第五集《沉钩之港》

完整可玩流程，故事 / 独立关卡 / Boss 挑战三个入口；等级 16–18。预计首次探索 25–35 分钟是设计目标，尚未以完整人工通关计时验证。

## 空间与节奏

第四集取得铸钟图纸后，霜暮营地南侧开放海路。雾岛港口采用中央船坞与东西两条栈桥的回环路线：清理并点亮两座航灯，打开中央锁链门，击败钩手船长拿钥匙。东南旧灯旁有可选藤壶守卫，领取领航符可降低潮浪和洪流伤害 20%。沿北航道进入沉船墓场，在左右残骸中破坏两根牵钟锁链，解除潮门，迎战奥尔古。取回潮汐钟舌，完成第四次反鸣，运单将下一集指向寒脊修道院。

地图以湿石码头、架空木栈桥、吊机、系船柱、绞盘、破船龙骨、残帆与暖色航灯区分前四集。海面、边缘泡沫与贴地海雾只存在于当前港口地图。海水和深渊边缘不可通行，位移、怪物移动、钩链拉拽都走同一套碰撞扫掠。

奥尔古 62,000 基础生命。使用独立深海鱼体、张合颌骨、弯曲利齿、鳍膜、腐蚀钟架与发光灯囊，隐藏原人形模型。湿润巨兽受雷电 +15%、火焰 -10%；常态承伤 85%，收招或破灯时承伤 125%。这些差异是配招优势，不构成某职业无法击败的硬门槛。

## 奥尔古：可读、可躲、可反击

- 100–70%：沉钩直线、前方深颚咬合、引灯、单次潮浪。
- 70–35%：加入三条平行甲板洪流，第一次转阶段最多补足两只溺亡水手。
- 35% 以下：双潮浪间隔 0.9 秒，收招间歇略缩短；存活召唤物仍封顶两只。

所有技能先锁定方向或落点，预警 1.05–2 秒。咬击可绕侧，沉钩可横移，洪流的三条水带间有空隙。潮浪从鱼体向外传播，留青色角度缺口，也可用带无敌的位移穿过，每条浪对每个目标最多伤害一次。引灯可用控制或蓄力期间的主动攻击破坏；持续伤害与召唤物不自动累积破灯，避免无操作无限压制。成功破灯获得 3.8 秒反击窗。失败后仍能离开原落点规避。

重招使用全游戏统一的生命比例伤害下限，装备护甲仍有效。洪流每 0.95 秒共用一次伤害判定，三条水带不叠加伤害。受潮汐命中后 5 秒内回复降低，每层 12%、最多三层；与其他回复抑制取最强者，不乘算叠加。领航符及专属靴子也同步减免比例下限，避免显示减伤却实际无效。

## 奖励

- 踏潮者的旧靴：潮浪 / 洪流伤害降低 25%。
- 断锚者之握：对收招或破灯中的敌人额外伤害 15%。
- 沉灯之眼：成功破灯回复 20 资源，8 秒内置冷却。
- 章节 Boss 保证掉落本章传奇；材料「沉潮藤壶」可出售。
